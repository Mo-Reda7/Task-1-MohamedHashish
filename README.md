# AI Chat Bot

## Description
A simple rule-based chatbot developed using Python. The chatbot can interact with users and provide predefined responses based on user input.

## Features
- Interactive conversation
- Simple response matching
- Easy to customize
- Command-line interface

## Technologies Used
- Python

## How to Run

1. Clone the repository
2. Open terminal
3. Run:

```bash
python main.py
```
